# 우리집 냉장고 🧊

냉장고 재고, 주간 식단표, 식비 가계부를 한 페이지에서 관리하는 모바일 우선 웹앱입니다.

## 기능

- **🧊 냉장고 재고** — 보관 구분(냉장/냉동/실온·양념), 품목명, 수량, 유통기한 관리. 유통기한 기준 D-day 배지(임박·만료 색 구분), 임박순 정렬, 임박/만료 필터, 원터치 '소진 완료'(되돌리기 가능)
- **🍽️ 주간 식단표** — 월요일 시작 주 단위로 아침·점심·저녁·메모 입력. 유통기한 임박 재료를 함께 보여주고, 재료를 눌러 식단 칸에 바로 넣기
- **💰 식비 가계부** — 장보기/외식/배달·카페/기타 구분, 날짜·금액·메모 기록. 월별 총 식비와 구분별 합계·비율, 월 예산 대비 남은 금액과 진행률 바
- **데이터 관리** — 자동 저장(localStorage), JSON 내보내기/불러오기, 전체 초기화

## 개인정보

- 모든 기록은 사용자의 브라우저 `localStorage`에만 저장됩니다. 서버로 전송되지 않습니다.
- 저장소에는 개인정보나 사용 기록이 포함되지 않습니다. 순수한 정적 파일뿐입니다.
- 로그인, 결제, 광고, 분석 도구, 외부 스크립트를 사용하지 않습니다.

## 구성

```
index.html            화면 구조
styles.css            스타일
app.js                앱 로직 (localStorage 저장)
manifest.webmanifest  홈 화면 추가용 매니페스트
icon.svg, icon-*.png  앱 아이콘
```

## 아이폰에서 홈 화면에 추가

Safari로 접속 → 공유 버튼 → **홈 화면에 추가**. 앱처럼 전체 화면으로 열립니다.

## 배포

GitHub Pages (main 브랜치, `/` 경로)로 서빙되는 정적 사이트입니다. 빌드 단계가 없습니다.
